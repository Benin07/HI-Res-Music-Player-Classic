Music Player
A simple desktop music player built with Python, Tkinter, and pygame.

Features
Playlist: add individual files or a whole folder (MP3, WAV, OGG, FLAC)
Play / Pause / Stop / Next / Previous controls
Seek bar with elapsed / total time display
Volume control
Auto-advance to the next track when the current one finishes
Double-click a playlist entry to play it
Requirements
Python 3.8+ (with Tkinter, included in most Python installs)
pygame
mutagen

pip install -r requirements.txt
Run

python music_player.py
